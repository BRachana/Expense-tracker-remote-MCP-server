# Expense Tracker - Ideal Directory Structure

## Project Layout

```
expense-tracker/
├── main.py                          # FastMCP server entry point
├── pyproject.toml                   # Project metadata & dependencies
├── uv.lock                          # Locked dependencies
├── README.md                        # Project documentation
├── HORIZON_SETUP.md                 # Horizon deployment guide
├── DIRECTORY_STRUCTURE.md           # This file
│
├── data/                            # Data directory (git-ignored)
│   ├── expenses.db                  # SQLite database (created at runtime)
│   └── .gitkeep                     # Ensure directory exists
│
├── config/                          # Configuration files
│   ├── categories.json              # Expense categories & subcategories
│   └── settings.json                # Future: app configuration
│
├── exports/                         # CSV exports directory (git-ignored)
│   └── .gitkeep                     # Ensure directory exists
│
├── logs/                            # Application logs (git-ignored)
│   └── .gitkeep                     # Ensure directory exists
│
└── .gitignore                       # Git ignore file
```

---

## Directory Purposes

### **`data/`** - Data Storage
- **expenses.db** - SQLite database (auto-created)
- **Purpose**: Persistent storage for all expense data
- **Git**: Ignored (don't commit database)
- **Backup**: Should be backed up separately

### **`config/`** - Configuration
- **categories.json** - Predefined expense categories
- **settings.json** - Future app configuration options
- **Purpose**: Static configuration that shouldn't change at runtime
- **Git**: Committed (version control important)

### **`exports/`** - Generated Files
- **CSV files** - Generated by `export_expenses_csv()` tool
- **Purpose**: User-generated reports and exports
- **Git**: Ignored (generated files)
- **Cleanup**: Can be deleted safely

### **`logs/`** - Application Logs
- **Purpose**: Debug and runtime logging
- **Git**: Ignored (runtime artifacts)
- **Rotation**: Can be rotated/cleaned periodically

## Configuration Updates

Update `main.py` to use these directories:

```python
# Directory paths
SCRIPT_DIR = Path(__file__).resolve().parent
DATA_DIR = SCRIPT_DIR / "data"
CONFIG_DIR = SCRIPT_DIR / "config"
EXPORTS_DIR = SCRIPT_DIR / "exports"
LOGS_DIR = SCRIPT_DIR / "logs"

# Ensure all directories exist
for dir_path in [DATA_DIR, CONFIG_DIR, EXPORTS_DIR, LOGS_DIR]:
    dir_path.mkdir(exist_ok=True)

# Database path
DB_PATH = os.getenv("EXPENSE_TRACKER_DB_PATH", str(DATA_DIR / "expenses.db"))
CATEGORIES_FILE = os.getenv("EXPENSE_TRACKER_CONFIG_PATH", str(CONFIG_DIR / "categories.json"))
```

## Environment Variables

For different environments, set these variables:

**Local Development:**
```bash
# Optional - will use default paths
export EXPENSE_TRACKER_DB_PATH=$(pwd)/data/expenses.db
```

**Horizon Container:**
```bash
# Set in Horizon deployment
EXPENSE_TRACKER_DB_PATH=/data/expenses.db
EXPENSE_TRACKER_CONFIG_PATH=/app/config/categories.json
```

**Docker:**
```bash
# In docker-compose.yml or Dockerfile
ENV EXPENSE_TRACKER_DB_PATH=/data/expenses.db
ENV EXPENSE_TRACKER_CONFIG_PATH=/app/config/categories.json
```

## Directory Creation

The directories should be auto-created by the application, but to ensure they exist:

```bash
# Create directories
mkdir -p data config exports logs

# Create .gitkeep files to ensure git tracks them
touch data/.gitkeep config/.gitkeep exports/.gitkeep logs/.gitkeep

# Commit
git add data/.gitkeep config/.gitkeep exports/.gitkeep logs/.gitkeep
git commit -m "chore: add directory structure with gitkeep files"
```

## Deployment Notes

### **Local Development**
```bash
uv run python main.py
# Uses: ./data/expenses.db
```

### **Horizon Deployment**
```bash
# The app will automatically use /data/expenses.db
# (or EXPENSE_TRACKER_DB_PATH if set)
```

### **Docker Deployment**
```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY . .

# Create data directory with proper permissions
RUN mkdir -p /data && chmod 777 /data

# Volume mount
RUN pip install -e .
ENTRYPOINT ["python", "main.py"]
```

In `docker-compose.yml`:
```yaml
services:
  expense-tracker:
    build: .
    volumes:
      - expense_data:/data
      - ./config:/app/config:ro
volumes:
  expense_data:
```

## Summary

| Directory | Purpose | Git | Auto-created |
|-----------|---------|-----|--------------|
| `data/` | Database & app data | ❌ Ignore | ✅ Yes |
| `config/` | Configuration files | ✅ Commit | ❌ Manual |
| `exports/` | Generated CSV exports | ❌ Ignore | ✅ Yes |
| `logs/` | Application logs | ❌ Ignore | ✅ Yes |

This structure makes the app:
- **Organized** - Clear separation of concerns
- **Portable** - Easy to deploy anywhere
- **Scalable** - Ready for containerization
- **Maintainable** - Clear what goes where
